# 智能仓储演示：资产与来源记录

## 资产策略

本页面采用混合程序化资产路线，目标是把技术灰盒提升到可展示的 L2–L3 质量，同时保持零外部模型下载和可快速修改。

| 资产 | 运行形态 | 来源 / 许可 | 说明 |
| --- | --- | --- | --- |
| 仓库外壳、立柱、屋架、窗带与顶灯 | Three.js 程序化几何 | 本项目代码生成；随项目 MIT 许可 | Box、RoundedBox、Plane 与灯光组合 |
| 货车、叉车、AMR、机械臂与月台 | Three.js 程序化几何 | 本项目代码生成；随项目 MIT 许可 | 货车使用敞开后门、尾板、尾灯与独立货厢面板；月台按车辆方向对接，不是导入模型 |
| 货架、托盘、纸箱、护栏、桶与警示柱 | Three.js 程序化几何 | 本项目代码生成；随项目 MIT 许可 | 重复零件复用材质，输送辊使用 InstancedMesh |
| 混凝土、纸箱、金属、警示条 | CanvasTexture 程序纹理 | 页面运行时生成；随项目 MIT 许可 | 不包含外部图片或贴图库内容 |
| FLOWDECK、安全标识与区域牌 | CanvasTexture / Sprite | 页面运行时生成；随项目 MIT 许可 | 仅为虚构演示标识 |
| 流动包裹、状态光环、路线与方向箭头 | 运行时效果 | 本项目代码生成；随项目 MIT 许可 | 随业务状态更新；入库从货厢后门卸货，出库由货厢后门装车 |
| README GIF、MP4、封面与字幕 | 本地浏览器录制 / FFmpeg 转码 | 本项目页面的第一方录制；随研究仓库发布 | 录制清单、参数与重新生成方式见 `images/demos/README.md` |
| Three.js 与 RoundedBoxGeometry | CDN 运行依赖 | Three.js MIT | 固定为 0.185.0 |

## 浏览器预算基线

2026-09-05 在 1440×900 浏览器视口、设备像素比上限 1.75 下观察：

- 约 409–501 draw calls；
- 约 47K–54K triangles；
- 13–15 个运行时纹理；
- 静态仓库阴影在首帧后缓存，运动包裹与设备不重复刷新整张阴影图；
- 无 GLB、图片、视频或音频下载负担。

实时值会显示在桌面页面右下角，不同 GPU、浏览器和视角会略有变化。

## 质量边界

当前资产适合概念演示、中景浏览和业务流程说明；它不是 L4 电影级或真实设备数字孪生。若用于正式品牌发布或产品近景，应接入经过许可与压缩的 GLB/PBR 资产，并重新验证模型比例、UV、贴图、LOD、加载状态和移动端预算。
