defineActor()

把 forms、states 和 timing 绑定成一个跨场景角色。

startMorph()

为所有 Actor 计算 from/to、行程、升力、延迟和持续时间。

1500

stepMorph()

执行位移、最短旋转、缩放和旧/新形态切换。

1593

tick()

统一更新转场、Shader、昼夜光照、控制器并渲染。

SCENE INDEX
  └─ ACTORS.forEach(actor)
       ├─ states[from] → states[to]       // CPU：空间状态
       ├─ forms[from]  → forms[to]        // CPU：语义换形
       ├─ position / rotation / scale     // CPU：时间插值
       └─ weights + uniforms              // CPU → GPU
             └─ shader → light → pixels   // GPU：最终画面

06 / SCALE LIMITS

扩展前必须知道的四个瓶颈

01

所有形态同时驻留当前用 scale=0 隐藏，不是卸载；场景越多，内存和遍历成本越高。

02

重复对象没有实例化花草由大量独立 Mesh 组成；规模扩大时应改为 InstancedMesh。

03

没有资源生命周期当前无需切换真实资产，所以没有 loader、缓存、取消和 dispose。

04

还是作品，不是工程底座单 HTML、CDN 依赖、无测试与降级；产品化需要构建、锁版本和 fallback。
