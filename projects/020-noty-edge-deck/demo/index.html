WINDOWS BLUEPRINT / 桌面实现

从网页原型，到真正驻留桌面的工具。

推荐用 Tauri 2 保留当前界面，以 Rust/Win32 补上窗口、快捷键和本地数据能力。网页负责体验，Windows 宿主负责“始终可达”。

01 / INTERFACE

界面与状态机

复用当前 HTML、CSS 和 JavaScript，保留 Rest、Fan、Expanded 三态以及主题、键盘和编辑反馈。

  • WebView2 渲染
  • 卡片协议
  • 响应式界面
02 / DESKTOP SHELL

Tauri 桌面宿主

管理无边框窗口、生命周期、系统托盘、单实例和应用权限，把网页变成可安装的轻量 EXE。

  • 无边框窗口
  • 托盘与自启动
  • 全局快捷键
03 / WINDOWS

Win32 窗口层

控制不抢焦点、置顶、隐藏于任务栏和 Alt+Tab，并根据当前显示器工作区贴靠左侧或右侧。

  • NOACTIVATE
  • TOOLWINDOW
  • 多显示器与 DPI
04 / LOCAL DATA

本地数据与安全

用 SQLite 保存卡片、标签和上下文；凭据进入 Windows Credential Manager 或由 DPAPI 保护。

  • SQLite
  • 导入与恢复
  • 凭据隔离
WINDOW STATE MACHINE

窗口不是打开或关闭，而是在三种注意力强度间切换。

REST

16–24px 边缘入口

置顶但不激活，不进入任务栏和 Alt+Tab；只承担“我在这里”的弱提示。

TOPMOST · TOOLWINDOW · NOACTIVATE
→
FAN

扩宽窗口，仍不抢焦点

鼠标停留或快捷键触发卡组预览，离开后延时收回，避免误触造成闪烁。

resize · hover/leave · keep focus
→
EXPANDED

临时获得编辑焦点

打开便签时允许激活；完成编辑后保存、恢复 NOACTIVATE，再缩回屏幕边缘。

activate · edit · persist · dismiss

多屏定位按鼠标所在显示器读取工作区，避开任务栏，并在 DPI 或显示器变化后重新贴边。

触发策略边缘悬停、点击胶囊和可配置全局快捷键同时存在；不使用全局鼠标钩子。

能力边界网页 Demo 模拟空间关系；只有桌面宿主才能覆盖其他应用、响应系统快捷键并随 Windows 启动。

官方依据： Tauri 插件 Windows 窗口样式 多显示器定位

BUSINESS FIT / 业务适配

适合短、频繁、跨应用，而且需要立刻回到原任务的事情。

它不是缩小版工作台，而是一个环境式入口。一次操作最好在几十秒内完成，复杂内容应转入完整工作区。

ACT / 轻操作

在边缘完成一次确认

审批 AI 建议、复制结果、切换环境、启动计时器或执行安全且可撤销的快捷动作。

  • 动作单一
  • 结果明确
  • 可快速撤销
三问判断法

是否值得放到屏幕边缘？

  1. 01一天会不会调用很多次？
  2. 02单次能否在几十秒内完成？
  3. 03完成后是否要立即回到原任务？

三个答案大多为“是”，才适合 Edge Deck。长文档、复杂表单、批量管理和强告警应该进入完整工作区。

EXTENSION MAP / 扩展路线

先扩卡片类型，再扩上下文，最后扩智能与协作。

扩展的原则是保持边缘入口克制：捕获、预览、选择和轻操作留在边缘；搜索、整理和协作进入独立工作区。

P0FOUNDATION

统一卡片协议

将便签、任务、剪贴板、文件和运行状态统一成 title、preview、payload、actions、context。

  • 组件化 Deck / Tab / Panel
  • SQLite、迁移、导入导出
  • 搜索与归档工作区
P1SYSTEM

接入 Windows 系统

加入托盘、开机启动、快捷键、左右贴边、多显示器和高 DPI，形成真正的常驻工具。

  • 剪贴板历史
  • 文件拖放与分享
  • 通知和任务状态
P2CONTEXT

让卡片理解当前环境

依据当前应用、项目、文件夹或浏览器 URL 召回相关卡组，但必须显式说明所读取的上下文。

  • VS Code 项目卡组
  • 会议与联系人上下文
  • 按应用切换工作集
P3INTELLIGENCE

AI 与团队协作

AI 用于分类、摘要、任务提取和语义召回；共享、评论与分派则由独立团队空间承接。

  • Agent 待确认收件箱
  • 本地优先的语义检索
  • 加密同步与共享卡组
