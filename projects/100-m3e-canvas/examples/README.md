# 演示工程

`message-flow.m3e-canvas.json` 是通过本地运行的 M3E Canvas 在真实浏览器中搭建并由应用自身“保存项目”功能导出的项目文件。

导入方式：启动 `../source/m3e-canvas` 后，在顶部“项目”菜单选择“打开项目”，再选择该 JSON 文件。

演示重点：

- 两个手机屏幕与画布流程连线。
- Blue / Full shape / Expressive motion 主题组合。
- App Bar、Card、FAB、列表、底部导航栏和 Connected button group。
- 点击跳转、返回栈和多种过渡。
- Android 与 Web 两种 Prompt 输出目标。

文件中不含 API Key、账号信息或外部数据。
