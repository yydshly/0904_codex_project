01

空间是导航，不只是背景

四个站点各自承载一类证据；选择站点时，镜头、灯光、DOM 文案与活动对象一起切换。

02

2D 内容能进入 3D 世界

右后方屏幕每帧由 2D Canvas 更新，再作为纹理映射到几何体，说明仪表盘、游戏或视频如何成为场景表面。

03

交互要有可感知后果

信号球采用轻量弹道、命中检测与粒子轨迹。物理不必复杂，但必须形成清楚的输入—反馈闭环。

04

最终画面可以再次被处理

场景先写入离屏纹理，再经全屏 Shader 加入色差、扫描线、噪声与暗角，形成统一的影像语气。

DEEP DIVE / MEMORY RESIDENCE

让房间保存人生，
而不是堆满模型。

记忆住宅最难的不是 Three.js，而是把个人内容转成可信的空间叙事。先确定哪些记忆值得进入房间，再决定需要制作哪些资产。

  1. 01
    门厅 · 我是谁

    用一件标志性物品建立身份，不在入口堆完整简历。

  2. 02
    客厅 · 我在乎什么

    照片、声音和生活物件建立情绪可信度与人与人的关系。

  3. 03
    书房 · 我做成过什么

    电脑、草图墙和样机承载真实项目证据，并打开 DOM 案例页。

  4. 04
    记忆走廊 · 我如何变化

    用年份、门与光线组织阶段，不用悬浮卡片代替故事。

  5. 05
    阳台 · 我想去哪里

    以安静的远景和一个明确行动结束体验，形成最终记忆点。

ASSET QUALITY GATE

素材决定上限，代码保证下限

L1叙事灰盒

基础几何、镜头和灯光，只验证房间关系与节奏。仅用于内部原型。

L2模块化住宅

购买或自制可授权的墙体、门窗与基础家具，统一比例、UV 和材质。

L3英雄物件

定制 5–8 件近景物品，加入真实照片、作品视频、声音与磨损细节。

L4真实空间捕捉

只在确有原型住宅时采用摄影测量或 3DGS；作为高成本可选层，而非默认路线。

DELIVERY ROADMAP

先做一间可信的房，
再扩成整套住宅

  1. 01情绪原型

    只做书房与一件英雄物件，验证光线、镜头、声音和案例打开方式。

  2. 02资产纵切

    把一个近景做到 L3，验证建模、贴图、压缩、加载和移动端预算。

  3. 03内容引擎

    以 JSON/MDX 驱动房间节点、媒体、DOM 详情、深链接和自动导览。

  4. 04生产加固

    加入分区懒加载、LOD、低性能模式、减少动态、隐私和素材授权清单。
