图片没有使用外部图片素材。图中的平台和技术名称仅用于说明开源项目的真实输入、依赖与数据流；精确、可维护的架构关系以项目 README 内的 Mermaid 图为准。

不依赖图片的文字描述：输入源经 yt-dlp、FFmpeg 和 ffprobe 采集；视觉流用低频灰度采样、ROI、SSIM、稳定检测与冷却去抖生成 `FrameEvent`；文字流优先使用 SRT/VTT 字幕，否则提取 16 kHz 音频，经 VAD 与本地或云端 ASR 生成 `TranscriptEvent`；两类事件写入原始时间线，再按时间中点、自然断句和停顿组织为 `Section`；可选 LLM 进行字幕润色、视觉术语纠正和视频总结；最终输出 Markdown、HTML、JSON、截图、元数据和运行记录。关键截图依据视觉变化而非字幕语义，当前没有完整 OCR、说话人分离、实时或服务端任务系统。
